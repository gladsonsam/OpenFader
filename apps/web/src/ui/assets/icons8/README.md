# Icons8 Color channel icons

43 locally bundled 100 × 100 PNG icons from Icons8 Color. No runtime CDN or API requests are required.

Free use with attribution: https://icons8.com/license. The application shell contains a visible, clickable Icons8 credit.

The typed catalogue in `../../icons.ts` defines stable IDs, labels, categories, and search keywords. Add a local asset and catalogue entry there to extend the picker. Keep existing IDs to preserve saved selections.
